# KIN Fieldbook

Public, anonymized evidence from the Kindred Instinct Network field lab.

This repository records what actually happened in KIN deployments: useful patterns, failures, corrections, permission problems and verified outcomes.

It does **not** contain participant identities, credentials, private correspondence, raw sensitive records, phone numbers, invite tokens, medical records or other private deployment data.

## Proof standard
A deployment is not VERIFIED until three real bounded tasks have evidence, the owner confirms the outcome/usefulness, failures are recorded, and no unsupported safety or sovereignty claim is made.

## Structure
- `case-studies/` — anonymized verified deployments
- `failures/` — useful failures and corrections
- `patterns/` — reusable deployment patterns
- `templates/` — publication-safe evidence templates

**One verified human outcome is worth more than ten speculative demos.**
